# Yankees Scores

Yankees Scores shows New York Yankees games and scores for a date you choose.

## Usage

Configure Wi-Fi in **Settings**, then open **Yankees Scores**. No MLB account
or API key is needed.

- Use **Left/Right** to choose year, month, or day and **Up/Down** to change
  it. Press **Select** to look up that date.
- If there is more than one game, use **Left/Right** to switch games.
- Press **Select** again to refresh, **Back** to edit the date, or **Home**
  to return to the badge menu.

Scores and game status come from the [MLB Stats API](https://statsapi.mlb.com/).
Dates are MLB schedule dates, not the badge's local time zone. A dash means
no score is available yet. Scheduled and postponed games are shown with their
status; dates with no Yankees game are labeled separately. Scores update
on demand, not in the background.
