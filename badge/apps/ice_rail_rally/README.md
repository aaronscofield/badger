# Ice Rail Rally

Ice Rail Rally is a downhill mine-cart game where you lean through bends and chain aerial stunts.

## Usage

Open **Ice Rail Rally** and press **Select** to ride. The cart accelerates as
you clear more bends, and the run ends after three derailments.

- **Left/Right:** Hold the indicated direction as you reach a bend. Stay on
  the track to make the turn.
- **Select:** Jump. In the air, press **Up** for a flip or **Left/Right** for a
  spin. Alternate tricks and land them to build a score multiplier.
- **Down:** Hold on straight track to grind for bonus points.
- **Menu:** Pause or resume. **Back** from pause returns to the title, and
  **Home** returns to the badge menu.

The best finished run is saved on the badge. No Wi-Fi is required.
